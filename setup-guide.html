1. Clone the project

The repository is public. HTTPS clone does not ask for a username or a password.

  1. Install Git for Windows from https://git-scm.com/download/win. Accept the defaults. Close Command Prompt if it was already open.
  2. Open a new Command Prompt and check Git: 
    git --version
  3. Go to the disk where you want the project. This example uses C:\: 
    cd /d C:\
  4. Clone. Git creates a new folder named Alice-project and puts every file inside it: 
    git clone https://github.com/kass2024/Alice-project.git
  5. Enter that folder and list it: 
    cd /d C:\Alice-project
dir
    You should see backend, frontend, app attendance, start.bat, and setup-guide.html.
  6. Open C:\Alice-project\setup-guide.html and continue from the database section.

This laptop already has the project at C:\methode\water_level\Alice project. Do not clone a second copy into that same folder. Use the folder you already have, or clone only on a new computer.

If Git asks for a password, the address is wrong. The public address is https://github.com/kass2024/Alice-project.git.

3. Install the programs once

Java (for Spring Boot)

  1. Download Temurin JDK 17, Windows x64, .msi from https://adoptium.net.
  2. Run the installer. Turn on Set JAVA_HOME and Add to PATH when those choices appear.
  3. Open a new Command Prompt: 
    java -version
javac -version
    Both must print a version. The project source is Java 11. JDK 17 runs it.

Maven (starts Spring Boot)

  1. Download apache-maven-3.9.9-bin.zip from https://maven.apache.org/download.cgi.
  2. Extract it so this file exists: C:\apache-maven-3.9.9\bin\mvn.cmd.
  3. Windows search: environment variables. Edit your user Path. Add C:\apache-maven-3.9.9\bin.
  4. Open a new Command Prompt and run mvn -version.

Node.js (for the website)

  1. Install the Windows LTS package from https://nodejs.org. Leave Add to PATH selected.
  2. New Command Prompt: 
    node -v
npm -v

XAMPP (the database server)

  1. Install XAMPP from https://www.apachefriends.org. This laptop uses C:\xampp7. A new PC often uses C:\xampp.
  2. Open mysql\bin\my.ini inside that XAMPP folder. Under [mysqld], set port=3307. Save the file.
  3. Open the XAMPP Control Panel and click Start next to MySQL. It must say Running.
  4. Test it. Change C:\xampp7 if your XAMPP lives somewhere else: 
    C:\xampp7\mysql\bin\mysql.exe -u root -P 3307 -e "SELECT 1"
    A result of 1 means MariaDB is up. The user is root with an empty password on this laptop.

Leave C:\xampp7\mysql\data\smart_teacher alone. This project uses the database name alice_teacher.

4. Configure the database name

Open this file in Notepad. It is the only database configuration:

File to edit

backend\src\main\resources\application.properties

On this laptop the full path is:

C:\methode\water_level\Alice project\backend\src\main\resources\application.properties

After a clone it is:

C:\Alice-project\backend\src\main\resources\application.properties

These lines must agree with each other and with my.ini. The database name is the word after the port in the URL, and again in app.db-name.

spring.datasource.url=jdbc:mariadb://localhost:3307/alice_teacher?createDatabaseIfNotExist=true&serverTimezone=Africa/Kigali
spring.datasource.username=root
spring.datasource.password=
app.mysql-bin=C:/xampp7/mysql/bin
app.db-name=alice_teacher
app.db-port=3307
app.db-user=root
app.db-password=
What you want to changeWhich lineExample
Database namealice_teacher in the URL, and app.db-nameChange both to the same new name. The API creates it if it is missing.
Database port3307 in the URL, and app.db-port, and port= in my.iniIf XAMPP stays on 3306, set all three to 3306.
Database userspring.datasource.username and app.db-userKeep root unless you created another MariaDB user.
Database passwordspring.datasource.password and app.db-passwordLeave both empty when root has no password. If root has a password, type the same password on both lines.
XAMPP folder for backupsapp.mysql-binC:/xampp/mysql/bin when XAMPP is not in C:\xampp7. Use forward slashes.

You do not create the database in phpMyAdmin. createDatabaseIfNotExist=true creates alice_teacher when the API starts. Hibernate then creates the tables. The first start also inserts the demo school when there are no users yet.

Save the file, then restart the API window if it was already running. A running API does not notice a saved properties file until you close that window and start it again.

Load the exported database

The file database\alice_teacher.sql is a full export of alice_teacher, including the demo accounts and sample rows. MariaDB must already be running. Import it before the first API start if you want this copy of the data. If the API has already created an empty database, this import replaces that database.

C:\xampp7\mysql\bin\mysql.exe -u root -P 3307 < "C:\Alice-project\database\alice_teacher.sql"

On this laptop the same command uses the project path. Run it in Command Prompt:

C:\xampp7\mysql\bin\mysql.exe -u root -P 3307 < "C:\methode\water_level\Alice project\database\alice_teacher.sql"

The SQL file creates the database alice_teacher. Change the name inside the file only if you also changed app.db-name.

5. Configure the Gemini key

AI analysis on the website needs a Google AI key. The key is not in the GitHub project. You add it on your own computer, in a file Git will not upload.

File you create (it does not exist after clone)

backend\gemini-key.local

On this laptop:

C:\methode\water_level\Alice project\backend\gemini-key.local

After a clone:

C:\Alice-project\backend\gemini-key.local

  1. Open Notepad. Paste your Gemini key. The file is one line only. No quotes, no word GEMINI, no spaces before the key.
  2. File → Save As. Go into the backend folder. Set Save as type to All files.
  3. File name, including the quotes so Windows does not add .txt: 
    "gemini-key.local"
  4. Save. In the backend folder you should see gemini-key.local, not gemini-key.local.txt.
  5. The line that reads this key is already in application.properties. Leave it like this. Do not paste the key into that file: 
    gemini.api-key=${GEMINI_API_KEY:}
gemini.models=gemini-2.5-flash-lite,gemini-2.5-flash,gemini-flash-latest
  6. start.bat reads gemini-key.local and passes it to the API as GEMINI_API_KEY. Close any old API window, then start the API again.

If you start Maven yourself, without start.bat

Command Prompt does not load gemini-key.local unless you set the variable. In the same window, before mvn:

set /p GEMINI_API_KEY=<gemini-key.local
mvn spring-boot:run

Run that from the backend folder. You can also add a Windows user environment variable named GEMINI_API_KEY and skip the file. A new Command Prompt is required after you create that variable.

Do not put the real key in application.properties, in this HTML guide, or in a Git commit. gemini-key.local is listed in .gitignore.

Attendance, login, and documents work with no Gemini key. Only AI analysis needs the key. If the key is missing, that page says to create backend/gemini-key.local and restart the API.

6. Start the Spring Boot API

  1. MySQL in XAMPP is Running, and the port matches app.db-port.
  2. Open Command Prompt in the backend folder. This laptop: 
    cd /d "C:\methode\water_level\Alice project\backend"
    After a clone: 
    cd /d C:\Alice-project\backend
  3. If you created the Gemini file and you are not using start.bat, load it, then start: 
    set /p GEMINI_API_KEY=<gemini-key.local
mvn spring-boot:run
  4. Wait until the window prints Smart Teacher API is ready. The first start downloads libraries and can take several minutes. On an empty database it also prints Login: admin / password123.
  5. Open http://localhost:8080/api/health. You should see {"status":"ok"}.

7. Start the React website

Use a second Command Prompt. Leave the API window open.

  1. Go into frontend: 
    cd /d "C:\methode\water_level\Alice project\frontend"
    After a clone: cd /d C:\Alice-project\frontend
  2. Once, install the libraries. This creates node_modules, which is not in GitHub: 
    npm install
  3. Start the site: 
    npm run dev
  4. Open http://localhost:5173. Sign in as admin / password123.

After Java, Maven, Node, XAMPP, npm install, the database file, and the Gemini file are done, a later day is only double-click start.bat. That file reads gemini-key.local, starts the API, and starts the website. If XAMPP is not in C:\xampp7, start MySQL from the XAMPP panel first.

8. Phone app

  1. The API health page must already say ok.
  2. In app attendance, run gradlew.bat assembleDebug. Install app\build\outputs\apk\debug\app-debug.apk.
  3. On the laptop run ipconfig. Copy the Wi-Fi IPv4 Address. The phone uses the same Wi-Fi.
  4. In the app, School server is http://THAT-IP:8080. Tap Test connection, then sign in as admin / password123.
  5. Enroll loads staff after you open it. Take photo saves a face. Remove deletes it. Verify names the teacher. The first clock of the day is check-in. A later clock is check-out.

An emulator on this laptop uses http://10.0.2.2:8080. If the phone cannot connect, allow inbound TCP 8080 for Java.

If something does not work

What you seeWhat to do
git clone asks for a passwordUse https://github.com/kass2024/Alice-project.git. The repository is public.
The clone folder is empty of backendYou are in the wrong directory. cd into Alice-project and run dir.
API says communications link failureMySQL is stopped, or port 3307 in application.properties does not match my.ini.
Unknown database, or the name looks wrongChange alice_teacher in the URL and app.db-name to the same name, then restart the API.
Access denied for user rootPut the MariaDB password in both spring.datasource.password and app.db-password.
Gemini key is missingCreate backend\gemini-key.local with the key on one line. Restart the API. start.bat loads that file. A manual mvn window must run set /p GEMINI_API_KEY= first.
The key file is named .txtNotepad added .txt. Save again as gemini-key.local with type All files.
localhost:5173 does not openRun npm install inside frontend, then npm run dev.
Port 8080 already in useClose the old Smart Teacher API window and start once.

Stop

Close the Smart Teacher API window and the Smart Teacher UI window. MySQL can stay running. Next time, double-click start.bat and open http://localhost:5173.
