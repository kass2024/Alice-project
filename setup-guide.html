0. Copy the project (no password)

The repository is public. git clone over HTTPS downloads it without a username or password.

  1. Install Git for Windows from https://git-scm.com/download/win. Keep the default options. Close and reopen Command Prompt after install.
  2. Check Git: 
    git --version
  3. Clone into a folder you choose. Example: 
    cd C:\
git clone https://github.com/kass2024/Alice-project.git
cd Alice-project
  4. Open setup-guide.html from that new folder and continue below. This laptop already has the files at C:\methode\water_level\Alice project, so you can skip the clone here.

If Git asks for a password, the address is wrong or the repository was made private. The public address is https://github.com/kass2024/Alice-project.git.

1. Install Java for Spring Boot

The API is compiled as Java 11 and runs on Java 11 or newer. Install Temurin JDK 17.

  1. Open https://adoptium.net and download JDK 17, Windows x64, .msi.
  2. Run the installer. Tick Set JAVA_HOME and Add to PATH if those boxes are shown. If they are not shown, the installer still adds Java for most PCs.
  3. Close every Command Prompt window, open a new one, and run: 
    java -version
    You want a line that says version 17 (or 11 or newer).
  4. Also run javac -version. If only java works and javac does not, you installed a runtime, not the JDK. Install the JDK again.

2. Install Maven (builds the Spring Boot API)

Maven downloads the Spring libraries and starts the API. Install it once.

  1. Download the binary zip apache-maven-3.9.9-bin.zip from https://maven.apache.org/download.cgi.
  2. Extract it to C:\apache-maven-3.9.9 so this file exists:

    C:\apache-maven-3.9.9\bin\mvn.cmd

  3. Press the Windows key, type environment variables, and open Edit the system environment variables.
  4. Click Environment Variables. Under your user variables, edit Path. Click New and add:

    C:\apache-maven-3.9.9\bin

  5. Click OK on every window. Open a new Command Prompt and run: 
    mvn -version
    It should print Maven 3.9.9 and the Java version.

On this laptop, a Maven copy also sits in .tools inside the project. That folder is not in GitHub. After a clone, use the Maven you installed above. start.bat uses .tools when that folder exists, and mvn from Path otherwise.

3. Install Node.js for the website

  1. Download the Windows LTS installer from https://nodejs.org.
  2. Run it. Leave Add to PATH selected. Finish the installer.
  3. Open a new Command Prompt: 
    node -v
npm -v
    Both commands must print a version.

4. Install the database (XAMPP MariaDB)

Spring Boot does not install a database. XAMPP provides MariaDB. The MySQL button in XAMPP starts that database. The API creates the database alice_teacher the first time it starts. User root, empty password, time zone Africa/Kigali.

  1. Download XAMPP for Windows from https://www.apachefriends.org.
  2. Install it. This laptop uses C:\xampp7. A new install often uses C:\xampp. Either path is fine.
  3. Open C:\xampp7\mysql\bin\my.ini (or C:\xampp\mysql\bin\my.ini) in Notepad.
  4. Find the line port=3306 under [mysqld] and set it to: 
    port=3307
    This project’s application.properties uses 3307. If you leave MariaDB on 3306, change both spring.datasource.url and app.db-port in backend\src\main\resources\application.properties to 3306 so they match.
  5. Save my.ini. Open the XAMPP Control Panel. Click Start next to MySQL. The module must show a green Running state.
  6. Test the port in Command Prompt. A result of 1 means MariaDB is up. Use the folder where you installed XAMPP: 
    C:\xampp7\mysql\bin\mysql.exe -u root -P 3307 -e "SELECT 1"

Do not delete C:\xampp7\mysql\data\smart_teacher. That is an old leftover folder. This project uses the database name alice_teacher only. If root has a password, put that password in spring.datasource.password and app.db-password.

You do not create tables by hand. On the first API start, Hibernate creates the tables. When the user table is empty, the API inserts the demo school.

5. Start the Spring Boot backend

The backend folder is backend. The main class is com.alice.smartteacher.SmartTeacherApplication. Port 8080.

  1. MariaDB must already be running (step 4).
  2. Open Command Prompt and go into the backend folder. On this laptop: 
    cd /d "C:\methode\water_level\Alice project\backend"
    After a clone, use the folder you cloned into, for example cd /d C:\Alice-project\backend.
  3. Start Spring Boot: 
    mvn spring-boot:run
    The first start downloads dependencies. Leave this window open. It can take several minutes.
  4. Wait until the window prints:

    Smart Teacher API is ready.

    On a brand-new database it also prints Login: admin / password123.
  5. Open a browser on the same laptop:

    http://localhost:8080/api/health

    The page must show {"status":"ok"}.
  6. Optional check that the database was created: 
    C:\xampp7\mysql\bin\mysql.exe -u root -P 3307 -e "SHOW DATABASES"
    alice_teacher is in that list.

Attendance from the phone uses action AUTO: no check-in yet means check-in; a check-in already saved means check-out; both times saved means already recorded. A teacher on leave is not changed.

6. Start the React website

The website is in frontend. Vite listens on port 5173 and forwards /api to http://localhost:8080. Start the backend first so the pages have data.

  1. Open a second Command Prompt. Leave the Spring Boot window running.
  2. Go into the website folder: 
    cd /d "C:\methode\water_level\Alice project\frontend"
  3. Install the libraries once (this creates node_modules, which is not in GitHub): 
    npm install
  4. Start the site: 
    npm run dev
  5. When the window shows a local address, open http://localhost:5173.
  6. Sign in with username admin and password password123.

Every later day, npm install is unnecessary unless the website dependencies change. Use npm run dev only.

7. Start everything the easy way

After Java, Maven, Node, and XAMPP are installed, and after npm install has been run once:

  1. Double-click start.bat in the project folder.
  2. It checks MariaDB on port 3307. If that check fails, it tries to start C:\xampp7\mysql\bin\mysqld.exe. If your XAMPP is in C:\xampp, start MySQL from the XAMPP panel yourself, then run start.bat.
  3. Two windows stay open: Smart Teacher API and Smart Teacher UI.
  4. Wait for Smart Teacher API is ready.
  5. Open http://localhost:5173.

8. Android app

The app folder is app attendance. Open that folder in Android Studio, not the whole project. The phone is the camera. Install Java and the API before you use the phone.

  1. Install Android Studio. The SDK on this laptop is C:\Users\user\AppData\Local\Android\Sdk.
  2. Build the install file from Command Prompt, with the internet on the first time: 
    cd /d "C:\methode\water_level\Alice project\app attendance"
gradlew.bat assembleDebug
  3. Copy this file to the phone and install it:

    app attendance\app\build\outputs\apk\debug\app-debug.apk

  4. On the laptop run ipconfig. Copy the IPv4 Address under Wireless LAN adapter Wi-Fi. The phone and the laptop must be on the same Wi-Fi.
  5. In the app, School server is http://YOUR-IP:8080 with no slash at the end. Tap Test connection, then sign in as admin / password123.
  6. Enroll loads the staff list after you open it. Take photo saves a face. Remove deletes a saved face.
  7. Verify names the teacher. The first clock of the day is check-in. A later clock is check-out. The camera then waits 12 seconds.

An emulator on this laptop uses http://10.0.2.2:8080. If the phone cannot connect, allow Java on private networks, or in an Administrator PowerShell run:

netsh advfirewall firewall add rule name="Smart Teacher API" dir=in action=allow protocol=TCP localport=8080

If something does not work

What you seeWhat to do
git clone asks for a passwordUse https://github.com/kass2024/Alice-project.git. The repository must stay public.
java or mvn is not recognizedInstall the JDK and Maven, add them to Path, then open a new Command Prompt.
npm is not recognizedInstall the Node.js LTS installer again and open a new Command Prompt.
MySQL will not start in XAMPPAnother program is using the port in my.ini. Match that port with application.properties.
API database errorMySQL is stopped, the port is not 3307, or root has a password.
Port 8080 already in useClose the old Smart Teacher API window and start once.
localhost:5173 does not openRun npm install inside frontend, then npm run dev.
Pages load and then show errorsThe API window is closed. Wait for Smart Teacher API is ready.
Health page is ok, Analyse failsCreate backend\gemini-key.local with your key on one line, then restart the API.
Phone Test connection failsUse the Wi-Fi IPv4 and port 8080. Allow the firewall rule. Keep the API window open.

Stop

Close the Smart Teacher API window and the Smart Teacher UI window. MySQL in XAMPP can stay running. Next time, start MySQL if it is stopped, double-click start.bat, and open http://localhost:5173.
